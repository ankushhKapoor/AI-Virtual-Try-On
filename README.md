# AI Virtual Try-On

This repository contains a frontend demo for an AI-powered virtual try-on platform.

## Contents

- `frontend/` – React + Vite application for product browsing, photo upload, virtual try-on, wishlist, saved looks, and history.
- `main.py` – unrelated top-level script outside the frontend app.
- `pyproject.toml` – project metadata for the workspace.

## Notes

The frontend is built as a standalone demo UI. It relies on browser local persistence and does not implement backend APIs, authentication, database storage, or payment processing.

For frontend development, open the `frontend/` folder and follow the instructions in `frontend/README.md`.
